# 💻 PC Desktop Suite — Windows Edition

A lightweight, offline-first productivity suite built for Windows laptops and desktop systems. Features live PC hardware diagnostics, offline notes, daily tasks with Pomodoro focus timer, PIN-protected secret vault, scientific calculator, file manager, and PDF studio.

---

## 🌟 Features

- **🪟 Windows Desktop Experience**: Windows 11 style titlebar, standalone window mode, and fullscreen toggle (`F11`).
- **⚡ 100% Offline**: Works completely without internet after first download.
- **💻 Hardware Monitor**: Visual CPU load, RAM usage, and drive capacity monitors.
- **📝 Offline Notes**: Fast notepad with search, word counter, and auto-save.
- **⏱️ Tasks & Pomodoro**: Daily task checklist and 25-minute Pomodoro focus timer.
- **🔐 Secret Vault**: 4-digit PIN secured credentials safe.
- **🧮 Calculator & Converter**: Scientific calculator and digital storage converter.
- **📁 File & PDF Manager**: Local file explorer and PDF reader.

---

## 💻 Requirements

- **Windows 10 or Windows 11**
- **Node.js** (v18 or higher) — [Download from nodejs.org](https://nodejs.org)

---

## 📥 Installation & How to Run

1. **Download the App**
   - Click the green **Code** button above and select **Download ZIP**.
   - Extract the ZIP folder anywhere on your computer.

2. **Launch the App**
   - Open the extracted folder and double-click:
     ```cmd
     Launch-PC-Desktop-Suite.bat
     ```
   > **Note:** On first launch, the batch script automatically installs all required dependencies (`npm install`) and opens the app in a dedicated Windows window.

3. **Install Shortcut (Optional)**
   - Click the **"Install on Windows"** button in the top bar to pin **PC Desktop Suite** directly to your **Desktop**, **Start Menu**, and **Taskbar**.
